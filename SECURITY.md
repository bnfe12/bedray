# Security policy

Bedray is a client-side Minecraft mod in **alpha**. It loads native libraries (DLLs) that you place in your game folder, so
please treat the following as security-relevant:

* Only use libraries from the official vendor sources listed in `docs/INSTALL.md`. Never use copies from forums, file-sharing
  sites or the game folders of other products.
* The mod never downloads anything and never sends data anywhere.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Use the "Report a vulnerability" button (private security advisory)
in the Security tab of this repository. Describe what you found and how to reproduce it. We aim to answer within a week; this is a
hobby project and there is no bounty.

## Supported versions

Only the latest release is supported.
