    How to install these files

    Download. Drop. Restart.

    1. Download the official DLL or ZIP.Keep the vendor's licence and use the version matched to your build.
    2. Open Bedray Settings → Runtime libraries.Drop the downloaded DLL or ZIP onto that screen. The importer handles recognised files and their folders.
    3. Restart Minecraft.Check the feature's runtime status. File presence and successful initialisation are separate checks.

    For manual installation, use bedray/natives/; Streamline files go in bedray/natives/streamline/. See every file and destination.

    My build is missing a Bedray wrapper

    vkb_dlss.dll, vkb_nrd.dll and vkb_sl.dll are Bedray integration libraries, not files supplied by those vendor links. Use a matching Bedray package that contains them, or build the matching wrappers. There is no separately published, player-ready wrapper download for the new renderer yet.

    A vendor DLL cannot replace a missing wrapper. Public distribution of SDK-linked objects follows the per-component licence policy.
